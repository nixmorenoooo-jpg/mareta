# Mareta - Tienda online

Réplica con fines académicos de la tienda de ropa urbana Mareta
(https://mareta.com), hecha con React, Vite y Tailwind CSS.

## Tecnologías

- React + Vite
- Tailwind CSS
- lucide-react y react-icons

## Componentes

- `AnnouncementBar`: barra de mensajes en movimiento
- `Navbar`: menú de navegación
- `Hero`: banner principal
- `ProductList` y `ProductCard`: carrusel de productos
- `CategoryGrid` y `CategoryCard`: grilla de categorías
- `StoreSection`: tienda física y mapa
- `Footer`: newsletter, ayuda y contacto
- `WhatsAppButton`: botón flotante

## Cómo ejecutarlo

1. Clonar el repositorio
2. `npm install`
3. `npm run dev`
4. Abrir http://localhost:5173
